# ARW 2026 Menu — Changes for the developer (Aug 29, 2026)

Everything in the project stands as you built it — `validate.js`, the 51-field contract,
the fixed 5 / 8 / 3 / 1 cardinality, the reflow/hide rules, the snapshot test, and the
Two-Column Classic template are unchanged. Three changes, all in the Left-Aligned style.

## 1. Thin gold rule under each course header (Left-Aligned only)

    .course-head {
      padding-bottom: 2.25pt;
      border-bottom: 1px solid rgba(184,130,30,.35);
      margin: 21pt 0 5.25pt;   /* bottom was 7.5pt */
    }

All three courses. The Classic template stays ruleless.

## 2. Featured cocktail block moved down (Left-Aligned only)

`.cocktail` top margin `7.5pt` → `27.75pt`. It now sits centered in the whitespace between
the hero and the Antipasti header: 37px above, 37px below, and the three `.menu-body`
space-between gaps also land at 37px. `.page.scrollHeight` = 1056 = `clientHeight`.

Don't hard-code the 37px gaps — the margin was solved against the current fixed margins.
Re-check page fit after any spacing or copy change.

## 3. Cocktail description may now wrap to two lines

Two lines is supported and is the maximum. The hanging indent already handles it (the second
line starts under the first word of the description, the price trails the last line), but the
extra line needs ~19px the page doesn't have after change 2, so `render.js` now tightens the
layout when it wraps — new `fitCourseSpacing()` step, already implemented in this handoff:

| Cocktail description | `.cocktail` margin-top | `.course-head` margin-top |
|---|---|---|
| 1 line (default) | `27.75pt` (CSS) | `21pt` (CSS) |
| 2 lines | `24.75pt` (inline) | `16pt` (inline) |

Both cases fit the page exactly. The inline styles are set and cleared on every render, so it
tracks live typing in both directions, and it no-ops on the Classic template and under JSDOM.
See BUILD-SPEC §4b.
